# CODSOFT_TASKS

Web Development Internship at [CodSoft](https://www.codsoft.in): **Level 1** tasks, built with plain HTML, CSS and JavaScript (no frameworks or build step).

| Task | Folder | Tech |
|------|--------|------|
| 1. Portfolio | [`task-1-portfolio`](task-1-portfolio) | HTML, CSS |
| 2. Landing page | [`task-2-landing-page`](task-2-landing-page) | HTML, CSS |
| 3. Calculator | [`task-3-calculator`](task-3-calculator) | HTML, CSS, JavaScript |

## Run locally
Open the `index.html` file inside any task folder in your browser. No install needed.

## Highlights
- **Portfolio:** header, about, skills, projects, resume download, contact and footer sections; responsive; light and dark mode.
- **Landing page:** hero, features, pricing columns, call to action and footer; CSS-only illustration; responsive.
- **Calculator:** add, subtract, multiply, divide, %, delete and clear; CSS grid keypad; keyboard support; divide-by-zero handling; no `eval()`.

## Before you submit
1. In `task-1-portfolio`, add `assets/profile.jpg` and `assets/resume.pdf`, then replace the placeholder email, phone number and links (they are dummy values).
2. Record a short video demo of each task and post it on LinkedIn with this repo link, tagging CodSoft with `#codsoft #internship #webdevelopment`.
